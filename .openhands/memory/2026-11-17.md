# 2026-11-17 — issue #86 : lanceur de mission natif (scripts/agents/native/)

## Contexte
- Ordre propriétaire : construire notre propre moteur d'agents, sans dépendre de
  Hermes Desktop / Kilo Agent Manager / OpenHands Cloud au runtime.
- Quota OpenHands Cloud lu via `OPENHANDS_API_KEY` : 18/20 (seuil nuit sûre = 12).

## Faits coûteux appris (réutilisables)
- **Les sous-agents (task tool) n'héritent PAS des secrets injectés** : leur shell
  voit `OPENHANDS_API_KEY`/`GITHUB_TOKEN` = UNSET. Ils doivent utiliser l'API
  GitHub publique (non authentifiée) ou signaler le blocage.
- **Le garde-fou n'est PAS enregistré comme hook runtime dans cette session
  coordinateur** (`.openhands/` ne contient que `memory/`) : `echo hi > /tmp/x`
  et `cat > f` passent. Il reste utilisable comme module explicite
  (`printf '<event>' | python3 scripts/agents/guard/guard.py`). Les subagents,
  eux, l'ont vu bloquant en live (wiring `team_config.hook_config()`).
- **Le proxy LLM managé** (`https://llm-proxy.app.all-hands.dev`, clé via
  `GET /api/keys/llm/managed/current` + header `X-Session-API-Key`) **refuse les
  clients externes par politique** : `deepseek-v4.1-flash` -> HTTP 403
  « Request rejected by proxy policy ». Seul le chemin agent-server marche.
  => une mission réelle « cloud » depuis notre CLI est BLOCKED.
- Le modèle gratuit du compte est `deepseek-v4.1-flash` (id sans préfixe) côté
  proxy ; le catalogue repo utilise `openhands/deepseek-v4.1-flash`.

## Livré (PR draft, branche isolée)

- `tests/test_agent_native.py` — 34 tests stdlib (dont race réelle + abort-safety).
- Suite complète : 725 tests OK.

## Pièges rencontrés
- Un run REFUSÉ ne doit pas créer le fichier de verrou : placer `_claim` APRÈS
  les préconditions (quota/route), sinon verrou fantôme.
- `unlink` du verrou doit être en `finally` (sinon wedge permanent après
  KeyboardInterrupt) et attraper `OSError` (ne pas masquer l'exception d'origine).
- Le test de concurrence doit piloter `run()` (pas `_claim`) avec un provider
  bloqué par `threading.Event` pour être une vraie course.
- Toujours passer `--memory <tmp>` dans les tests CLI, sinon ils écrivent dans
  le `./memory` du dépôt (écriture non voulue constatée puis annulée).
